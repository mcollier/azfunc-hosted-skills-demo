# Security Policy

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Instead, please report them to: `no-reply@email.com`

Include the following in your report:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You will receive a response within 48 hours acknowledging the report. We will
work with you to understand and address the issue before any public disclosure.

We will credit reporters in release notes unless you prefer to remain anonymous.

## Disclosure Policy

When a vulnerability is confirmed, we will:

1. Develop and test a fix
2. Release a patched version
3. Publish a security advisory on GitHub
4. Credit the reporter (with permission)
